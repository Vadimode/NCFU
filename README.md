## Содержание лабораторных работ

### 1. Лабораторная работа №1 — Настройка среды разработки. Первая программа
* **Темы:** структура программы на C++ (`#include`, `int main()`, `return 0`), пространство имён `std`, потоковый ввод-вывод (`std::cout`, `std::cin`), манипуляторы вывода (`std::endl`, `\n`), базовые принципы структурного программирования.
* **Уровни заданий:**
  * *Базовый уровень:* вывод сообщений и выполнение простых арифметических вычислений.
  * *Средний уровень:* обработка двух величин, работа с разными типами данных (`int`, `double`), форматирование вывода (`std::fixed`, `std::setprecision`).
  * *Повышенный уровень:* составные выражения, проверка корректности ввода (`std::cin.fail()`), обработка граничных значений.

### 2. Лабораторная работа №2 — Переменные и арифметические операции
* **Темы:** встроенные типы данных (`int`, `short`, `long long`, `unsigned int`, `float`, `double`, `char`, `bool`), неявное и явное приведение типов (`static_cast`), целочисленное и вещественное деление, усечение и математическое округление (`std::round`), потеря точности (`float` vs `double`) и переполнение.
* **Уровни заданий:**
  * *Базовый уровень:* прямые вычисления с корректным выбором типа данных.
  * *Средний уровень:* вычисления с использованием явного приведения типов и именованных констант (`const`).
  * *Повышенный уровень:* анализ накопления погрешности вычислений, сравнение точности типов и проверка граничных значений.

### 3. Лабораторная работа №3 — Ветвления. Логические операторы
* **Темы:** условные операторы `if`, `if-else`, `if-else if-else`, вложенные ветвления, логические операторы (`&&`, `||`, `!`), ленивые вычисления (short-circuit evaluation), сравнение вещественных чисел с допуском (`EPSILON`), тернарный оператор `?:`, защита от деления на ноль и некорректного ввода (`std::cin.fail()`, `std::cin.clear()`, `std::cin.ignore()`).
* **Уровни заданий:**
  * *Базовый уровень:* простое ветвление с одним условием.
  * *Средний уровень:* множественное ветвление и сложные логические условия.
  * *Повышенный уровень:* многоуровневые ветвления с полной защитой от некорректных пользовательских данных.

### 4. Лабораторная работа №4 — Множественный выбор (`switch`)
* **Темы:** оператор множественного выбора `switch-case`, ключевое слово `break` и предотвращение непреднамеренного проваливания (*fall-through*), группировка `case`, обработка значений по умолчанию через `default`, работа с целочисленными типами и `char`, вложенные конструкции `switch`, сравнение `switch` и `if-else if-else`.
* **Реализация (`lab4/`):**
  * `task1/task1.cpp` — *базовый уровень*: одиночный `switch-case` на 4–7 вариантов с обязательным использованием `break` и `default`.
  * `task2/task2.cpp` — *средний уровень*: группировка ветвей `case` (намеренный *fall-through*), работа с типом `char` и полная обработка некорректных значений.
  * `task3/task3.cpp` — *повышенный уровень*: вложенные операторы `switch` (многоуровневое меню), проверка потока ввода через `std::cin.fail()` и очистка буфера.

## Сборка и запуск

Исходный код написан на стандартном C++ (C++17) и может быть скомпилирован с помощью `g++`, `clang++` или MSVC (Visual Studio).

### Компиляция через `g++` (MinGW / Linux / macOS)

```bash
g++ -std=c++17 lab4/task1/task1.cpp -o task1
./task1
```

### Запуск в Visual Studio
1. Откройте нужный `.cpp`-файл или решение `.sln` в Visual Studio.
2. Соберите проект (`Ctrl + Shift + B`) и запустите без отладки (`Ctrl + F5`).
